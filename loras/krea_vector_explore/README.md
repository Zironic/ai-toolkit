# Krea Vector Explore LoRAs

Drop source LoRA files for the Krea vector exploration runs here.

Expected contents are local experiment inputs such as .safetensors, .pt, or .ckpt files. These files are ignored by git; keep recipes, inspection output, and generated grids under output/lora_vector_explore/.

Example config path:

    lora:
      path: loras/krea_vector_explore/example.safetensors
